# Beautiful-Katamari-REX360-Recomp
Static Windows recomp of Beautiful Katamari (Xbox 360, USA). Main release contains the game (no game .iso extract files, move yours into the assets folder) in Beautiful Katamari REX360 Recomp 1.0, along with a folder containing the code generated to make this build for community improvement! Screen has common emulator glitch where the left side is blacked out on menus until an option is selected.
Place extracted game files from USA .iso into the assets folder and run using launch.bat!
